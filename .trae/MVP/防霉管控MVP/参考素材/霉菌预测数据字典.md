# 霉菌生长概率预测 - 数据字典

## 1. 环境数据定义

### 1.1 室内环境数据

| 字段名 | 数据类型 | 单位 | 精度 | 采集频率 | 正常范围 | 危险阈值 | 说明 |
|--------|---------|------|------|---------|---------|---------|------|
| **room_temp** | float | °C | ±0.1°C | 5分钟 | 18-28°C | >28°C或<15°C | 房间温度 |
| **room_humidity** | float | %RH | ±1%RH | 5分钟 | 40-60%RH | >70%RH | 房间相对湿度 |
| **wall_temp** | float | °C | ±0.1°C | 10分钟 | 18-26°C | <露点温度+2°C | 墙体表面温度 |
| **floor_temp** | float | °C | ±0.1°C | 10分钟 | 18-24°C | <露点温度+1°C | 地面温度 |
| **air_quality** | int | AQI | - | 15分钟 | 0-50 | >100 | 室内空气质量指数 |
| **co2_level** | int | ppm | ±50ppm | 15分钟 | 400-800 | >1000 | 二氧化碳浓度 |
| **voc_level** | float | mg/m³ | ±0.01 | 15分钟 | 0-0.2 | >0.5 | 挥发性有机物浓度 |
| **illumination** | int | lux | ±10 | 30分钟 | 100-500 | <50 | 光照强度 |

### 1.2 室外天气数据

| 字段名 | 数据类型 | 单位 | 精度 | 更新频率 | 说明 |
|--------|---------|------|------|---------|------|
| **outdoor_temp** | float | °C | ±0.1°C | 1小时 | 室外温度 |
| **outdoor_humidity** | float | %RH | ±1%RH | 1小时 | 室外相对湿度 |
| **weather_condition** | string | - | - | 1小时 | 天气状况（晴/雨/雪/雾） |
| **precipitation** | float | mm | ±0.1 | 1小时 | 降水量 |
| **wind_speed** | float | m/s | ±0.1 | 1小时 | 风速 |
| **wind_direction** | int | 度 | ±1° | 1小时 | 风向 |
| **atmospheric_pressure** | float | hPa | ±0.1 | 1小时 | 大气压 |
| **uv_index** | int | - | - | 1小时 | 紫外线指数 |
| **forecast_24h** | json | - | - | 6小时 | 24小时天气预报 |

### 1.3 时间相关数据

| 字段名 | 数据类型 | 格式 | 说明 |
|--------|---------|------|------|
| **timestamp** | datetime | YYYY-MM-DD HH:MM:SS | 数据采集时间 |
| **season** | string | 春/夏/秋/冬 | 季节 |
| **time_of_day** | string | 早晨/上午/中午/下午/傍晚/夜间/深夜 | 时间段 |
| **is_weekend** | boolean | true/false | 是否周末 |
| **days_since_cleaning** | int | 天 | 距离上次清洁天数 |
| **days_since_ventilation** | int | 天 | 距离上次通风天数 |

## 8. 数据存储结构

### 8.1 实时数据表（real_time_data）
```sql
CREATE TABLE real_time_data (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    room_id VARCHAR(50) NOT NULL,
    timestamp DATETIME NOT NULL,
    room_temp FLOAT,
    room_humidity FLOAT,
    wall_temp FLOAT,
    outdoor_temp FLOAT,
    outdoor_humidity FLOAT,
    mold_risk_score FLOAT,
    risk_level VARCHAR(20),
    INDEX idx_room_time (room_id, timestamp)
);
```

### 8.2 预测结果表（prediction_results）
```sql
CREATE TABLE prediction_results (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    room_id VARCHAR(50) NOT NULL,
    prediction_time DATETIME NOT NULL,
    forecast_hours INT,
    mold_risk_score FLOAT,
    risk_level VARCHAR(20),
    confidence FLOAT,
    alert_level VARCHAR(20),
    INDEX idx_room_prediction (room_id, prediction_time)
);
```

### 8.3 历史统计表（daily_stats）
```sql
CREATE TABLE daily_stats (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    room_id VARCHAR(50) NOT NULL,
    date DATE NOT NULL,
    avg_temp FLOAT,
    avg_humidity FLOAT,
    max_risk_score FLOAT,
    risk_duration INT,
    alert_count INT,
    energy_saved FLOAT,
    UNIQUE KEY unique_room_date (room_id, date)
);
```

## 9. 数据接口定义

### 9.1 REST API

#### 获取实时数据
```http
GET /api/v1/rooms/{room_id}/realtime
Response:
{
    "room_id": "room_001",
    "timestamp": "2025-12-10 14:30:00",
    "room_temp": 22.5,
    "room_humidity": 65.2,
    "wall_temp": 21.8,
    "mold_risk_score": 0.35,
    "risk_level": "低风险"
}
```

#### 获取预测结果
```http
GET /api/v1/rooms/{room_id}/prediction?hours=24
Response:
{
    "room_id": "room_001",
    "prediction_time": "2025-12-10 14:30:00",
    "forecast_hours": 24,
    "predictions": [
        {
            "timestamp": "2025-12-10 15:00:00",
            "mold_risk_score": 0.42,
            "risk_level": "中等风险"
        },
        ...
    ]
}
```

#### 控制设备
```http
POST /api/v1/devices/{device_id}/control
Request:
{
    "command_type": "启动",
    "target_humidity": 55.0,
    "duration_minutes": 30,
    "auto_mode": true
}
```

## 10. 数据安全与隐私

### 10.1 数据加密
- 传输加密：HTTPS/TLS 1.3
- 存储加密：AES-256
- 数据库加密：字段级加密

### 10.2 访问控制
- API认证：JWT Token
- 权限管理：基于角色的访问控制（RBAC）
- 审计日志：记录所有数据访问

### 10.3 数据保留
- 实时数据：保留7天
- 预测数据：保留30天
- 统计数据：保留3年
- 日志数据：保留1年
