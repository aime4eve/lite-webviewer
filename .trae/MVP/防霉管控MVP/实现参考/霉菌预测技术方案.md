# 霉菌生长概率预测技术方案

## 项目概述

本方案设计了一套完整的霉菌生长概率预测系统，从数据定义、算法开发、场景应用到效果展示，提供端到端的技术解决方案。

---

### 1.2 技术栈

#### 感知层
- **传感器**: DHT22温湿度传感器、CO2传感器、VOC传感器
- **通信**: LoRaWAN、WiFi、4G/5G
- **控制器**: ESP32、STM32单片机
- **网关**: LoRaWAN网关、边缘计算网关

#### 数据层
- **实时数据库**: InfluxDB（时序数据）
- **关系数据库**: PostgreSQL（配置数据）
- **缓存**: Redis（实时状态）
- **消息队列**: RabbitMQ、Kafka

#### 平台层
- **后端**: Python Flask/Django、Java Spring Boot
- **算法**: Python NumPy、Pandas、Scikit-learn
- **机器学习**: TensorFlow/PyTorch（深度学习模型）
- **容器化**: Docker、Kubernetes

#### 应用层
- **Web前端**: Vue.js、React.js
- **移动端**: Flutter、React Native
- **数据可视化**: ECharts、D3.js
- **报表**: JasperReports、Pentaho

完整的演示系统请参考 **mold_prediction_demo.py** 文件，包含以下功能：

### 5.1 系统功能

#### 实时数据监测
- 模拟环境数据变化（温度、湿度、天气等）
- 5分钟间隔数据采集和处理
- 实时霉菌风险计算

#### 霉菌概率预测
- 实时预测当前霉菌生长概率
- 计算各因子得分（温度、湿度、时间等）
- 确定风险等级和预警信息

#### 未来24小时预报
- 基于当前数据预测未来风险
- 生成风险趋势图
- 标注高风险时段和建议措施

#### 历史数据统计
- 统计平均温湿度、最高风险等
- 计算趋势变化
- 评估应用效果

#### 预警和建议
- 根据风险等级自动生成预警
- 提供针对性的处理建议
- 记录预警历史
