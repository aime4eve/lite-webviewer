# SmartMoldGuard 项目 H5 预览说明

## 项目预览

本项目已部署为H5页面，可以直接在浏览器中预览。访问 `index.html` 文件即可查看项目演示页面。

## 完整项目运行方式

要运行完整的uni-app项目，请按以下步骤操作：

### 1. 安装 Node.js 依赖
```bash
npm install
```

### 2. 启动 H5 开发服务器
```bash
npm run dev
```
或
```bash
npm run serve
```

这将启动开发服务器并在浏览器中打开H5预览页面（通常在 http://localhost:8080）。

### 3. 构建生产版本
```bash
npm run build
```

## 项目目录结构

- `pages/` - 各个功能页面
  - `index/index.vue` - 首页控制面板
  - `device/` - 设备管理页面
  - `subscription/index.vue` - 订阅中心
  - `risk/rooms.vue` - 风险房间清单（B端）
  - `ops/dashboard.vue` - 运维控制台
  - `profile/index.vue` - 个人中心

- `static/css/common.css` - 全局样式文件

- `App.vue` - 应用根组件

- `main.js` - 应用入口文件

- `pages.json` - 页面路由配置

## 功能模块

1. **首页控制面板**
   - 风险指数显示
   - 设备状态监控
   - 防霉战报统计

2. **设备管理**
   - 设备添加与绑定
   - 设备详情配置
   - 联动策略设置

3. **订阅服务**
   - 套餐选择与购买
   - 权益管理
   - 积分系统

4. **B端管理**
   - 高风险房间监控
   - 批量操作功能

5. **运维控制台**
   - 设备告警处理
   - 工单管理系统

## 技术特点

- 响应式设计，适配移动端和桌面端
- 基于 uni-app 框架开发
- 支持多端统一开发（H5、小程序、App）
- 完整的用户交互体验
- 符合SmartMoldGuard业务需求的设计

## 开发注意事项

- 项目目前为前端界面实现，未集成后端API
- 所有数据为模拟数据
- 页面跳转和交互功能已实现
- 可在此基础上集成真实API数据
