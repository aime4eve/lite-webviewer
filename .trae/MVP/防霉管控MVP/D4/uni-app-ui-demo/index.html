🛡️ SmartMoldGuard

防霉管控系统演示

这是一个基于uni-app框架开发的防霉管控系统前端应用。

该项目展示了以下功能：

  • 🏠 家庭设备管理
  • 🌡️ 实时环境监测
  • 🚨 霉菌风险预警
  • 🤖 智能联动控制
  • 💎 云订阅服务
  • 📊 数据报告分析

页面预览

🏠 首页控制面板 📱 设备详情页 💎 订阅中心 📋 风险房间清单 💻 运维控制台

项目说明

完整的项目代码在以下目录中：

D4/uni-app-ui-demo/

要运行完整的uni-app项目，请使用：

npm install
npm run dev:h5
