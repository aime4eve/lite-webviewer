#### 8.4.1 用户管理上下文

**职责**：管理用户身份、认证、权限、状态，为其他上下文提供用户信息。

**核心聚合**：
- `User` (用户): 聚合根。包含用户基本信息、状态、权限。
- `UserProfile` (用户档案): 实体。用户扩展信息（头像、昵称、偏好设置）。
- `UserPermission` (用户权限): 值对象。用户权限集合。

**领域服务**：
- `UserRegistrationService`: 用户注册服务
- `UserAuthenticationService`: 用户认证服务
- `UserAuthorizationService`: 用户授权服务

**领域事件**：
- `UserRegistered`: 用户注册事件
- `UserActivated`: 用户激活事件
- `UserDeactivated`: 用户禁用事件
- `UserUpdated`: 用户信息更新事件

**集成模式**：
- 与**身份认证上下文**：Conformist（顺从者），使用微信OAuth2/JWT
- 与**订阅上下文**：Customer/Supplier（客户/供应商），订阅状态影响用户权限

#### 8.9.1 门户网站登录/注册交互流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant P as 门户网站
    participant A as 认证服务
    participant S as 订阅服务

    U->>P: 点击C端/B端入口卡片
    P->>P: 显示登录/注册弹窗
    
    alt 微信一键登录
        U->>P: 点击微信一键登录
        P->>A: 调用微信OAuth2.0获取code
        A->>A: 通过code获取openid和用户信息
        A->>A: 检查openid是否已注册
        alt 已注册用户
            A->>A: 生成JWT Token
            A->>P: 返回token和用户信息
        else 新用户
            A->>A: 创建用户账户
            A->>S: 触发首月免费订阅激活
            S->>A: 返回订阅信息
            A->>A: 生成JWT Token
            A->>P: 返回token和用户信息
        end
        P->>U: 导航到C端/B端首页
    else 手机号注册/登录
        U->>P: 输入手机号
        U->>A: 点击获取验证码
        A->>A: 发送短信验证码
        A->>P: 返回验证码有效期
        U->>P: 输入验证码和密码
        alt 注册新用户
            P->>A: 提交注册信息
            A->>A: 创建用户账户
            A->>S: 触发首月免费订阅激活
            S->>A: 返回订阅信息
            A->>A: 生成JWT Token
            A->>P: 返回token和用户信息
        else 登录已有用户
            P->>A: 提交登录信息
            A->>A: 验证手机号和密码
            A->>A: 生成JWT Token
            A->>P: 返回token和用户信息
        end
        P->>U: 导航到C端/B端首页
    end
```
