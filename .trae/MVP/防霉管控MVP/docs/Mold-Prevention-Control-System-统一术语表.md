# Mold Prevention Control System 统一术语表

> **版本**: v2.0
> **制定日期**: 2025-12-14
> **制定依据**: 基于防霉管控MVP所有设计文档的术语提取和统一
> **维护责任**: 业务架构师（业务术语）、技术架构师（技术术语）
> **使用要求**: 所有相关设计文档、代码、测试用例必须使用本术语表定义的术语

---

## 1. 使用说明

### 1.1 术语表结构
- **术语 (Term)**: 标准术语名称（中英文）
- **定义 (Definition)**: 清晰、无歧义的定义
- **分类 (Category)**: 业务/技术/领域/角色
- **权威来源 (Source)**: 首次明确定义的文档
- **相关术语 (Related)**: 关联术语
- **使用示例 (Example)**: 正确使用示例

### 1.2 术语管理原则
1. **一致性原则**: 同一概念在所有场合使用相同术语
2. **权威性原则**: 以本术语表为最终权威，冲突时以本表为准
3. **可追溯原则**: 每个术语有明确的来源文档
4. **渐进明晰原则**: 术语定义可以随认知深入而细化，但需更新本表

### 1.3 术语变更流程
1. 发现新术语或术语定义需要更新
2. 提交术语变更申请（说明理由和影响范围）
3. 业务架构师和技术架构师评审
4. 更新本术语表并通知所有相关人员
5. 相关文档同步更新

## 2. 核心领域术语 (Core Domain Terms)

### 2.1 环境与气候相关

| 术语 | 定义 | 分类 | 权威来源 | 相关术语 | 使用示例 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **微气候 (Microclimate)** | 建筑物内部（特别是浴室）的局部温湿度环境，包含湿度变化率、露点等特征参数 | 领域 | CDS-04 | 环境数据、温湿度 | "当前微气候显示露点正在接近墙面温度" |
| **环境数据 (Environmental Data)** | 传感器采集的原始数据，包括温度、湿度、气压等物理量 | 技术 | BCM-02 | 遥测数据、传感器读数 | "环境数据每10分钟上报一次" |
| **遥测数据 (Telemetry Data)** | 通过远程通信方式传输的环境数据，特指通过LoRaWAN上报的数据 | 技术 | CIT-06 | MQTT、数据上报 | "遥测数据通过MQTT主题发布" |
| **露点 (Dew Point)** | 空气在水汽含量和气压不变的条件下冷却到饱和时的温度，是判断结露风险的关键参数 | 领域 | CDS-04 | 微气候、湿度 | "当墙面温度低于露点时可能产生结露" |

## 5. 关键指标与SLA术语

### 5.1 核心业务指标

| 指标 | 定义 | 计算公式/测量方法 | 目标值 | 数据来源 |
| :--- | :--- | :--- | :--- | :--- |
| **有效霉菌阻断数** | AI预测风险>0.8并成功触发设备干预，且干预后2小时内湿度<60%的次数 | ∑(风险>0.8 ∧ 干预成功 ∧ 2h后湿度<60%) | 月均≥10次/户 | 预测服务+控制服务日志 |
| **预测准确率** | 模型预测结果与实际发霉情况的一致性 | (TP+TN)/(TP+TN+FP+FN) | ≥92% | 人工复核+图像识别 |
| **单点运维成本降低率** | 相比传统人工巡检模式节省的运维成本比例 | (传统成本-实际成本)/传统成本 | ≥40% | 财务系统+运维工单 |
| **订阅转化率** | 硬件激活用户转化为付费订阅用户的比例 | 付费用户数/硬件激活用户数 | ≥80% | 用户数据库+支付记录 |

### 5.2 技术SLA指标

| 集成方向 | 延迟要求 (P95) | 可靠性要求 | 一致性 | 失败策略 |
| :--- | :--- | :--- | :--- | :--- |
| **Connectivity → Prediction** | <1s | 99.9% | 最终一致 | 丢弃过期数据，断点续传 |
| **Prediction → Control** | <500ms | 99.99% | 最终一致 | 滑动窗口限流，优先处理高风险 |
| **Control → Connectivity** | <200ms | 99.5% | 强一致 | 指数退避重试3次，失败入DLQ |
| **Control → Subscription** | <50ms | 99.9% | 弱一致(TTL 5m) | 降级为默认权限，异步修复 |

## 6. 文档引用规范

### 6.1 文档命名规范
- **D1产品愿景**: `PROD-VISION-SmartMoldGuard-{YYYYMMDD}-v{版本}.md`
- **D1用户故事**: `USER-STORIES-SmartMoldGuard-{YYYYMMDD}-v{版本}.md`
- **D2战略设计**: `DDD-STR-SmartMoldGuard-{YYYYMMDD}-v{版本}-{类型}.md`
  - 类型: `01-BVC`, `02-BCM`, `03-SDM`, `04-CDS`, `05-BCX`, `06-CIT`, `07-Roadmap`
- **D3战术设计**: `DDD-TAC-SmartMoldGuard-{YYYYMMDD}-v{版本}-{类型}.md`

### 6.2 文档引用示例
在文档中引用其他文档时使用格式：
```
参见《文档名称》（文档编号）
```
示例：
```
业务价值主张定义参见《01-BVC业务价值画布》（DDD-STR-SmartMoldGuard-20251209-v2.0-01-BVC）
```

### 6.3 术语引用规范
在文档中首次使用术语时，应标注术语表引用：
```
微气候 (Microclimate)【术语表2.1】
```
后续使用可直接使用术语。
