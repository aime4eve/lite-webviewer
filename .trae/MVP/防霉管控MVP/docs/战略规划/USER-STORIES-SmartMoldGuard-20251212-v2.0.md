## 二、用户旅程泳道图 (User Journey Map)

### 旅程 A: 首次配置与服务订阅 (Provisioning & Subscription)
*适用场景：新设备上电，首次使用，激活服务*

```mermaid
sequenceDiagram
    participant User as 用户
    participant Dev as LoRa设备
    participant GW as LoRa网关
    participant IoT as 物联网平台
    participant Sub as 订阅系统
    participant MP as 用户小程序

    autonumber
    User->>Dev: 1. 设备通电
    Dev->>GW: 发送入网请求 (Join Request)
    GW->>IoT: 转发入网请求
    IoT->>IoT: 验证设备合法性 (DevEUI/AppKey)
    IoT->>GW: 下发入网接受 (Join Accept)
    GW->>Dev: 转发配置参数
    Dev->>GW: 上报设备在线 (DeviceOnline)
    IoT->>IoT: 设备状态更新为 Ready
    
    User->>MP: 2. 打开小程序
    MP->>User: 提示“请输入设备SN码绑定”
    User->>MP: 输入SN码 (Scan/Type)
    MP->>IoT: 请求绑定 (User + SN)
    IoT->>Sub: 创建订阅账户 (Trial)
    Sub->>IoT: 订阅已激活
```

### 旅程 D: 资产保全闭环 (Asset Protection Loop)
*适用场景：设备被拆除/离线，运维侧*

```mermaid
sequenceDiagram
    participant S as 传感器
    participant GW as LoRaWAN网关
    participant Ops as 运维上下文
    participant DB as 数据库
    participant MP as 用户小程序

    autonumber
    S--xGW: 设备被强拆 (防拆开关弹起)
    GW->>Ops: 上报 DeviceTampered 事件
    Ops->>DB: 更新设备状态(异常)
    Ops->>DB: 读取租赁模式与押金余额
    Ops->>Ops: 计算应赔付金额，并拆分为押金抵扣金额与需补差金额
    Ops->>MP: 推送"设备异常告警 & 押金抵扣+补差赔付方案"
    MP->>S: 用户收到通知，查看详情
    alt 用户确认人为损坏
        S->>MP: 点击"确认赔付"
        MP->>Ops: 扣减押金并发起补差支付
        Ops->>DB: 记录押金抵扣与补差支付结果，关闭工单
    else 用户确认误触
        S->>S: 重新安装好设备
        S->>GW: 恢复心跳
        GW->>Ops: 上报 DeviceOnline
        Ops->>MP: 推送"设备已恢复，谢谢配合"
    end
```
