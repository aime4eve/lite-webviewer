## 1. 低保真用户界面原型 (Lo-Fi UI Prototypes)

说明：以下为文字版线框，仅用于表达布局与交互要点，设计细节与视觉风格留待后续 UI 设计阶段细化。

### 1.1 微信小程序 —— 家庭端首页（C 端用户）

```text
+------------------------------------------------------+
| 顶部栏: 防霉守护 · 家庭版           [齿轮 图标]      |
+------------------------------------------------------+
| 卡片1: 今天浴室防霉状态                               |
|  - 风险指数: 18% (安全)                               |
|  - 湿度: 62%   温度: 24℃                              |
|  - 状态标签: [安全] [自动防霉已开启]                  |
+------------------------------------------------------+
| 卡片2: 设备概览                                       |
|  [主卧浴室]   在线 · 正常 · 自动联动已配置  [详情 >]   |
|  [次卧浴室]   在线 · 正常 · 仅预警模式      [详情 >]   |
+------------------------------------------------------+
| 卡片3: 本月防霉战报                                   |
|  - 阻断霉变次数:  12 次                              |
|  - 估算节省电费:  ¥4.8                               |
|  - 防霉积分:      180 分   [兑换 >]                  |
+------------------------------------------------------+
| 底部导航: [首页] [设备] [订阅] [我的]                |
+------------------------------------------------------+
```

关键交互：
- 点击设备行进入 1.2「设备详情与联动配置」。
- 点击「防霉积分」进入 1.3「订阅与权益中心」。

- 若开关与设备映射变更，将影响智能控制上下文中的策略执行。

## 3. 故事板 (Storyboards)

故事板以「场景分镜」形式，帮助非技术干系人直观理解关键业务链路和订阅策略。

### 3.1 故事板一：家庭用户 —— 首次安装与自动配网

对应：Story 4「首次配置自动配网」+ 旅程 D。

```text
分镜 1:
  画面: 浴室中，用户手持新到货的传感器与 LoRa 开关面板，旁边有简单安装说明。
  文案: “首次使用防霉系统，无需预约安装，只要通电即可。”

分镜 2:
  画面: 用户合上开关面板电源，小程序首页弹出“发现新设备”提示。
  文案: “系统自动识别设备上线，提醒用户完成绑定。”

分镜 3:
  画面: 小程序「设备详情与联动配置」界面，用户将开关位1映射为排风扇，开关位2映射为加热器。
  文案: “几步完成设备联动配置，形成适合自家浴室的防霉策略。”

分镜 4:
  画面: 小程序弹出“配置完成，开始守护浴室”的确认提示，同时显示当前订阅状态为“试用中 · 剩余30天”。
  文案: “系统进入试用期，开始自动防霉与能耗记录。”
```

### 3.2 故事板二：家庭用户 —— 黄梅季自动防霉与积分激励

对应：Story 3「智能联动与能耗感知」+ CDS 中夜间风险阻断流程。

```text
分镜 1:
  画面: 夜间浴室湿气弥漫，窗外下着小雨，墙角隐约有霉斑。
  文案: “黄梅季夜间湿度飙升，传统排风方式不够灵敏。”

分镜 2:
  画面: 后台「智能控制系统」示意图，实时曲线显示湿度上升，风险指数突破阈值。
  文案: “系统监控到湿度与温度组合异常，预测 3 小时后霉变概率 > 70%。”

分镜 3:
  画面: 3 位开关面板上的排风按键被自动点亮，随后加热按键在需要时也自动点亮。
  文案: “先开启排风，若效果不足，再按策略自动联动加热烘干。”

分镜 4:
  画面: 清晨用户打开小程序，看到提示：“昨夜已为您阻断霉菌风险 1 次，耗电 0.5 度，获得防霉积分 +10。”
  文案: “用户获得可感知的结果反馈与积分激励，更愿意长期订阅服务。”
```

### 3.3 故事板三：订阅试用到期与平滑降级

对应：CDS SCEN-005「试用到期与权限降级」+ BVC/BCM 中订阅模型。

```text
分镜 1:
  画面: 小程序「订阅与权益中心」上方显示“试用剩余 3 天”，下方有基础版与加热增强版套餐对比。
  文案: “试用期接近尾声，系统提前提醒用户选择适合的订阅方案。”

分镜 2:
  画面: 用户当天忙于工作，忽略了提醒，试用到期当天小程序顶部出现黄色提示条：“当前为预警模式，自动干预功能已暂时关闭。”
  文案: “即便用户尚未付款，系统仍保留风险预警能力，保障基本安全。”

分镜 3:
  画面: 夜间湿度再次突增，系统在后台检测到高风险，只向小程序推送“高风险预警”通知，不再自动开启设备。
  文案: “根据订阅状态，控制权限被平滑降级为‘仅预警不干预’模式。”

分镜 4:
  画面: 用户点击通知，进入订阅页面，看到本次未执行自动干预的原因说明，同时提供“一键开通基础防霉版/加热增强版”的按钮。
  文案: “风险与权益被透明呈现，用户理解差异并做出订阅决策，形成正向转化闭环。”
```
