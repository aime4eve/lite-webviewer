# 碳排优化MVP —— 「产品愿景」

产品名称：智慧园区碳排优化生态系统（Smart CarbonZero Ecosystem）

版本：V1.0

发布日期：2025年12月10日

---

## 1. 产品定位

一句话愿景：

**"打造园区能源的'数字神经系统'，让每一度电都绿得透明，让每一个园区成为会呼吸的零碳生命体。"**

核心价值：

**通过端边云协同AI技术+空间数字孪生，构建全要素能源闭环管理，实现园区能耗主动优化与碳排精准控制，助力“双碳”目标低成本落地。**

## 2. 目标用户画像

| 用户类型 | 痛点需求 |
| - | - |
| 园区运营方（主打） | 能源账单不透明，设备管理粗放（人走灯亮），节能指标压力大，缺乏数字化抓手来实现降本增效。 |

## 3. 功能愿景（场景化描述）

### 3.1 核心场景：从“事后统计”到“实时智控”

用户故事：

> 夏日午后14:00，电网负荷达到尖峰。AI模型预测30分钟后园区变压器负载将超限。系统自动下发指令：将办公区空调设定温度上调1℃（人体无感），释放储能设备电量，并暂停景观喷泉等非必要负载。
> 
> 结果：成功削峰填谷，避免了需量电费罚款，单次节省电费2000元。园区经理收到推送：“今日已为您自动优化能源调度1次，预计节约成本2000元，降低碳排1.5吨。”

### 3.2 技术实现路径

| 层级 | 设计亮点 |
| - | - |
| 感知层 | **先进前端感知探针**：部署高精度传感器网络，实时采集能耗、碳排、环境质量等多维数据，支持多种无线协议。 |
| 边缘层 | **自适应智能边缘设备**：具备非法接入拦截（成功率≥95%），实现数据本地清洗与3秒内快速响应控制（时延≤3S）。 |
| 平台层 | **深度学习碳排放模型**：基于AI算法构建动态预测模型，实现精准碳足迹分析与能源储供动平衡调度。 |
| 应用层 | **空间+资产数字孪生**：构建三维可视化园区模型，实现全要素动态仿真，“所见即所得”的精细化管理。 |

## 4. 非功能愿景

### 4.1 安装即服务（IaaS）

- **“无侵入式部署”**：采用无线物联终端与卡扣式互感器，无需停工停产，无需破坏原有装修，快速完成园区感知网络覆盖。
- **“多协议兼容”**：边缘网关支持≥3种主流工业/无线协议，打破设备孤岛，实现新老设备统一接入。

### 4.2 云端闭环服务

- **“数字能源管家”**：7x24小时AI巡检，自动诊断能效异常（如设备空转、线路老化），提供预测性维护建议。
- **“持续进化”**：基于海量园区数据训练，AI模型持续迭代，每季度推送更优的节能策略算法。

| - | - | - |

| 专业版（智控） | 硬件费 + 年费 ¥15万起 | 包含AI优化控制功能，承诺综合节能率≥10%，提供能源储供动平衡策略。 |

### 5.2 资产与退出机制

| 场景 | 用户权益 |
| - | - |
| 服务期内 | 硬件故障免费更换（非人为），软件功能持续升级，享有专属客户经理服务。 |
| 合同到期 | 数据完整归属用户，可导出所有历史能耗与碳排数据；硬件归用户所有，保留本地基础控制功能。 |
| 提前终止 | 需支付剩余合同期30%的违约金，协助进行数据迁移与账号注销。 |

### 5.3 客户留存设计

- **“节能分润（EMC）”**：对于大型园区，可采用“零首付+节能效益分享”模式，降低客户决策门槛，绑定长期利益。
- **“绿色金融对接”**：利用平台数据信用，协助优质企业对接低息绿色贷款或碳交易市场，增加平台粘性。

### 5.4 财务模型（单园区生命周期价值）

| 项目 | 数据（预估平均值） |
| - | - |
| 获客成本（CAC） | ¥50,000（含售前方案、招投标、渠道佣金） |
| 年服务费（ARPU） | ¥150,000 |
| 平均生命周期 | 5年（园区基础设施更换周期长） |
| LTV（5年） | ¥150,000 × 5 = ¥750,000 |
| 硬件毛利 | 30%（自研边缘网关与终端） |

### 5.5 风险对冲条款

- **“节能承诺保”**：若连续一年未达到承诺的节能效果（如降低5%），按比例退还部分服务费或延长服务期。
- **“政策合规保”**：承诺平台算法与报表模板随国家双碳政策免费同步更新，确保客户始终合规。
